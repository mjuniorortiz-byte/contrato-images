# Como Fazer Upload das Imagens

As 5 imagens do contrato estão prontas para upload. 

## Opção 1 - Via Web (Mais Rápido)
1. Abra: https://github.com/mjuniorortiz-byte/contrato-images
2. Clique em "Add file" > "Upload files"
3. Arraste as 5 imagens para a área
4. Commit

## Opção 2 - Via Terminal (Com nomes descritivos)
```bash
cd /caminho/para/images
gh release upload v1.0 *.png --repo mjuniorortiz-byte/contrato-images
```
